## Method (G-PID)

- Crash event time = Application Error (1000) `TimeCreated` (local wall-clock).
- Dump file write time recorded separately when a dump exists; neither substitutes for the other.
- Serve launches have two `python.exe` pids (venv launcher + interpreter). A match states which of the pair when known.
- Prefer: dump/AE pid ↔ `zola_memory.store_open pid=` ↔ supervisor serve `stale`/`restart` + generation; exclude watcher/phone `job_assigned` pids. Timing-only links are **INFERENCE**.
- Zola.Client.exe rows: event-log fields only (no dumps).
